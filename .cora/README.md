# .cora test artifacts

These files are repo-specific instructions for testing rule, skill, and workflow pickup in this storefront project.

## Rules
- `rules/storefront-ux.md` — premium Apple-style UX and accessibility guardrails
- `rules/composition-and-content.md` — keep landing-page structure compositional and content data-driven
- `rules/checkout-behavior.md` — keep cart and checkout behavior deterministic and testable

## Skills
- `skills/landing-copy/SKILL.md` — refine landing-page copy without breaking structure or navigation consistency
- `skills/storefront-change/SKILL.md` — implement focused storefront or checkout changes
- `skills/e2e-check/SKILL.md` — verify user-visible behavior with the existing Playwright coverage

## Workflows
- `workflows/update-hero-copy.md` — refine hero copy with matching test updates when needed
- `workflows/add-promo-card.md` — add or refine promo cards through existing data structures
- `workflows/verify-checkout-flow.md` — verify or fix cart and checkout behavior with testable changes
